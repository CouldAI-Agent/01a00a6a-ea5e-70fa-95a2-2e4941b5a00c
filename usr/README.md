# Crochet Amigurumi Patterns

यह ऐप 200 से अधिक Crochet Amigurumi डिज़ाइनों का एक शानदार संग्रह प्रस्तुत करता है। इसमें 8 अलग-अलग मुख्य श्रेणियां (चित्र) हैं, और प्रत्येक श्रेणी में 40 अनोखे पैटर्न दिए गए हैं।

## मुख्य विशेषताएं
- **8 मुख्य श्रेणियां:** ऐप के होम स्क्रीन पर 8 अलग-अलग चित्र/श्रेणियां दिखाई गई हैं।
- **विस्तृत पैटर्न:** हर एक श्रेणी में 40 अलग-अलग Crochet Amigurumi पैटर्न की सूची है।
- **आकर्षक डिज़ाइन:** ऐप का लेआउट मोबाइल और वेब दोनों के लिए उपयुक्त है और एक सुंदर और रंगीन ग्रिड व्यू प्रदान करता है।

## तकनीकी जानकारी
- यह ऐप Flutter का उपयोग करके बनाया गया है।
- सभी प्लेटफॉर्म्स (Android, iOS, Web, Desktop) पर काम करता है।
- सुचारू नेविगेशन के साथ रेस्पॉन्सिव UI डिज़ाइन।

## कैसे चलाएं
ऐप चलाने के लिए निम्नलिखित कमांड का उपयोग करें:
```bash
flutter run
```
